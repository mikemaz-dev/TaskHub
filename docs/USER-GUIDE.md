# Using TaskHub

[← Documentation](../README.md#documentation)

## Start a project

Sign in with an email link and complete your profile. Open Projects → New project, choose a name, optional deadline, and color. The creator becomes the project owner.

Use Invite to project to generate a code. Share it with a teammate; they sign in and paste it into Team → Join a project. Owners can promote members to admins from the project team list.

## Plan and complete work

Create a task from the dashboard, project, or schedule. Choose the project and due date, optionally add start/end time and participants. Time shortcuts set a same-day duration. Edit the checklist to break work into concrete steps.

Task progress is completed checklist items divided by total checklist items. An empty checklist is an open task. Completing a project is a separate project-level action; it does not silently mark every task complete.

Use the schedule's Day, Week, or Month view. The day/week grid scrolls through all 24 hours. Time-range buttons follow the visible hours and jump to their section; navigation and weekdays remain fixed.

## Communicate

Messages lists people you share projects with. Choose a teammate and a shared project, then write your message.

| Key | Action |
| --- | --- |
| Enter in composer | Send message |
| Shift+Enter | Insert a new line |
| Cmd/Ctrl+K | Focus task search |
| Escape | Close an open control or dialog |
| Arrow keys in date calendar | Move by day or week |

Input-method composition does not trigger an accidental send. The sidebar shows unread message and activity counts. Notifications can be marked individually or all at once.

## Understand reports

Charts group tasks by due date. Planned hours come from start/end times and do not measure time actually worked. Reports filter by scheduled date; completion reflects the current checklist, not historic completion at that date. Export CSV or use browser print to save a PDF.

## Archive and personalize

Complete or archive a project from its page. It leaves the active workspace and appears in Archive with its retained tasks and conversations. Owners can restore archived projects; owners/admins can reopen completed projects from their project page.

Settings includes profile editing, avatar upload, dark/light/system theme, and accent colors. Theme and accent are saved on the current device.

### Planning and project conversations

New tasks must use today or a future date. Timed tasks today cannot start before
 the current local minute. **Now** selects today and the current time; duration
 shortcuts use the selected start, or the current time when empty. Tasks cannot
 cross midnight. Existing tasks remain available for historical review.

Scroll inside the planner hours to browse the full day. Time-range buttons jump
 to their hours and follow the scroll position; the navigation and weekdays stay
 above the scrolling area. Past days can be viewed, but their expired slots cannot
 create tasks.

Choose a project above a private conversation to see its separate message history.
 The composer repeats the project name so you can confirm where your message goes.
 Notifications describe checklist changes as task steps.

General is a private conversation with the selected teammate, without a project.
Use it to discuss ideas or plan a future project. Each project and General keep
separate message histories and drafts. General requires the general-conversations
migration described in the database guide.

Project cards and the sidebar distinguish projects you created from invited projects.
Inside a project, your role is shown beside its origin. Members see View team;
owners and admins see Invite & manage team. The expandable role guide describes
permissions before you assign a role. Project chat opens private conversations
with teammates filtered to that project; it is not a group chat room.
